# Vaelora ground enrichment studies · v1

Three source studies for the [terrain variety exploration](../../../docs/terrain-variety.md).
These do not have a runtime loader and are not additional Map Studio materials.
The runtime continues to use the thirteen checkpointed grounds.

| Study | Intended placement |
| --- | --- |
| `meadow-flowers` | Bellweather: sparse ivory flower, clover and straw patches amid quiet sage ground. |
| `woodland-roots` | Underbough: copper leaf clumps and shallow root fragments around woodland edges. |
| `salt-bone-earth` | Ru’Lora: sterile salt dust, small bone splinters and petrified debris. |

[Preview](preview.png) · [Prompts, source identifiers and hashes](manifest.json).
PNG sources are copied from built-in OpenAI image_gen. The root and bone studies
were repainted from project-generated first passes to remove excessive granular
realism; their initial prompts and reference output identifiers are retained in
the manifest. No third-party reference imagery was used. WebPs are 1024-square
RGB candidates encoded with Pillow 12.3.0, LANCZOS resize, quality 86.

These accents should be blended into localized habitat patches or split into
small independent ground decals, not repeated as the whole biome floor. Large
root/bone motifs still need scale and repetition review before runtime admission.
