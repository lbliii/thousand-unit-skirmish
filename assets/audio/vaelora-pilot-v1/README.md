# Vaelora audio pilot sources

Seven original MP3 files downloaded 30 September 2026 from the subscribed ElevenLabs [pilot flow](https://elevenlabs.io/app/flows/fvHx5prtAQnXfCiRKcZz).

The `sources/` folder contains Ellionar and Ru’Lora music sketches; wood token, iron latch, muted pluck, and two horn takes. Bellweather remains missing: its previously completed result is no longer exposed in the current flow or music history. No replacement was generated.

[manifest.json](manifest.json) records exact prompts, requested settings, original download filenames, byte counts, and SHA-256 hashes. Every file was verified byte-for-byte against its download. Music files are stereo MP3 at 48 kHz / 192 kbps; effects are stereo MP3 at 44.1 kHz / 128 kbps. The extra horn take's generation time is unknown.

These sources await audition, cue editing, and runtime integration. Requested tempo, key, and instrumentation have not been verified by listening.
