The original [Frontier environment library](environment/frontier-v1/PROVENANCE.md)
and [interactive states](environment/frontier-interactive-v1/PROVENANCE.md)
use provenance/manifests with their maintained guides in
[environment art](../docs/environment-pack-v1.md) and
[environment states](../docs/environment-state-pack-v1.md).

New packages should include a README with purpose, maturity, contents, root-based
rebuild/validation commands, runtime integration, known limits, and provenance links.
Keep exact prompts, provider IDs, source hashes, and licenses as records rather
than rewriting them as descriptive prose.
