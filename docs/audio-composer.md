# Clip composer

Audio Studio mounts `mountAudioComposer(container, {pack, sourceBlobs, onChange})` when an author opens the composition editor. The editor creates and selects version 1 compositions, adds tracks and recording clips, and sends the updated full pack to `onChange` when Save succeeds. The library owns storage; the editor never changes source Blobs. Imported recordings and provenance therefore remain intact through edits.

Each clip starts on a beat, has a beat length and a source offset in seconds. The BPM controls the timeline grid and bar length. Audio plays at its recorded speed; the first version does not stretch recordings to fit the beat grid or synthesize notes. A clip can repeat from its offset to the end of the source recording until the clip ends. Track gain, pan, mute and solo and clip gain and fades affect playback and WAV export. Click the timeline to place a selected clip on the nearest beat; use Start beat and Length for precise placement and trimming. Duplicate makes another editable clip using the same original recording.

`validateComposition` normalizes records and rejects unsupported versions, duplicate or invalid IDs, nonfinite numbers, invalid ranges and clips extending beyond the song. `compileComposition` converts beats to a single seconds timeline and applies track mute, solo and gain. Preview dynamically imports the shared `createCompositionPlayer` from the runtime lane. WAV export uses `OfflineAudioContext` and the same compiled event schedule; it decodes source Blobs in memory and writes 16-bit stereo PCM. Decode errors, missing recordings and unavailable browser audio rendering are shown in the editor. Preview requires the runtime player to be present after integration.

The saved composition contains references and edit metadata only. A WAV export is a rendered copy; the original recording bytes are not modified. Portable backup and player distribution are handled by the audio library pack workflow. WAV export is limited to five minutes to bound browser memory use. The first version has no piano roll, note sampler, waveform editing or automatic tempo matching.

Run `node scripts/audio-composer-scenario.mjs` for timing, validation, two-track save/reopen and WAV scheduling checks. The browser fixture at `scripts/audio-composer-browser.html` loads two generated quarter-second WAVs. On 27 September 2026, a browser pass created two tracks, looped the first source, placed the second source at beat four, saved and reopened the composition, then rendered a four-second stereo WAV. Preview uses the runtime player after that module lands in the integrated tree.
